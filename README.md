Entry for the make.fun bounty [Say What Actually Broke](https://make.fun/bounty/u-po-pu-say-what-actually-broke-a2c153b5).

The program (`main.ts`, Node 22, standard library only) writes one line
of honest error copy — 90 characters that name the real failure — to
`entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, or
`/output` by default). The update was called "minor". It was not
minor. Your work is saved; the team's dignity is not.

Run it with:

```sh
node main.ts
```
